## Setup & Config

### git config
       What it does: Sets user configuration values
       Example:
       git config --global user.name "Manjunath"

## Basic Workflow

### git init
       What it does: Initializes a new Git repository
       Example:
       git init

### git add
       What it does: Stages files for commit
       Example:
       git add git-commands.md

### git commit
       What it does: Saves staged changes to repository
       Example:
       git commit -m "Added git commands file"

## Viewing Changes

### git status
       What it does:Shows current state of working directory
       Example:
       git status

### git log
       What it does:Shows commit history
       Example:
       git log

### git diff
       What it does:Shows changes between commits
       Example:
       git diff
